## 薄弱点 / 待复习

- **证明跳步**：关键不等式（如 1/x 题中对分母 |x| 的下界估计）直接写结论，没写推理。要求每个 < 都有依据。
- **极限运算法则逆用**：由 lim(A+B)=0 推出 lim A = lim B = 0 —— 错。加法法则只在各项极限都存在时“正向”成立。
- 判断“条件 ⇒ 连续？”时，先检查条件是否约束到 f(x₀)。
- **< 与 ≤ 混用**：由 |x−1| < δ 写成了 ≤，导致后续严格不等号对不上。
- **反例要对照目标逐项检查**：(b) 题给的 x² 满足了条件，但没有满足“极限不存在”这个目标。
- **只给结论不给理由（已出现 3 次）**：T2 分母估计、T3 反例、追问 (b) 都是这样。从第 2 课起，“写出理由”单独评分。
- **举反例要验证**：给出反例后必须逐条说明“满足条件”且“结论不成立”。
