### 第 3 课待交练习（已布置）

1. **习题 3**：f 在 x₀ 处连续，g 在 x₀ 处不连续。(a) f ± g 是否一定不连续？证明（提示：反证法，g = (f+g) − f）。(b) f·g 呢？分别举出连续和不连续的例子并验证。(c) f、g 都不连续时，f+g、f·g 的情况如何？举例说明。
2. **习题 4**：(1) 用 ε-δ 证明 f 连续 ⇒ |f| 连续（用 ||a|−|b|| ≤ |a−b|）。(2) f、g 在 I 上连续 ⇒ max(f,g)、min(f,g) 在 I 上连续（用 max(a,b) = (a+b+|a−b|)/2）。
3. **习题 2**：对任意 0 < ε < (b−a)/2，f 在 [a+ε, b−ε] 上连续 ⇒ f 在 (a,b) 内连续（关键：让 x₀ 落在区间**内部**）。
4. **习题 12（挑战）**：lim_{x→x₀} g(x) = a ≠ g(x₀)，f 在 a 处连续 ⇒ lim_{x→x₀} f(g(x)) = f(a)（模仿定理 2.5 的证明，第 2 步用极限定义，注意 0 < |x−x₀|）。

参考答案要点（给老师看）：3(a) 一定不连续；3(b) 例如 f ≡ 0 时 f·g 连续，f ≡ 1 时 f·g = g 不连续；3(c) sgn + (−sgn) 连续，sgn + sgn 不连续，等等。

## 主要薄弱点（详见 progress.md）

- **只给结论不给理由**：已出现 4 次以上，是头号问题。
- **极限运算法则不检查前提**：出现 2 次。一次是由 lim(A+B)=0 推出各项极限为 0；一次是分母 → 0 时仍套用商的法则。
- **符号判断**：1/(0⁻) 写成 +∞；把"分母 → ∞"误当成"分式 → ∞"。
- **书写**：漏写 lim，把极限和函数值混写；< 和 ≤ 不分。
- **反例**：给了反例却不验证；所给反例不满足题目要求的目标。
- 第 2 课检验题的订正基本是照抄讲解，建议之后让学习者合上笔记重写一遍。
