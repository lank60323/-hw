## 二、推荐书目

| 书 | 说明 |
|------|------|
| 蒲和平《大学生数学竞赛教程》 | 俗称「大绿书」，按章节整理竞赛题型，最常用的一本。习题解析见 [hoganbin/Math-Competition-Problem-Solving](https://github.com/hoganbin/Math-Competition-Problem-Solving)。 |
| 陈兆斗《大学生数学竞赛习题精讲》 | 题量更大，适合时间充裕的同学。 |
| 《全国大学生数学竞赛真题解析与获奖名单（第 11–15 届）》（佘志坤主编，科学出版社） | 官方系的真题解析。 |
| 吉米多维奇《数学分析习题集》 | 题太多，不要全做，按专题挑着练。 |

## 三、可以参考的 GitHub 备考笔记

- [Iamnotphage/CMC-SpeedRun](https://github.com/Iamnotphage/CMC-SpeedRun)：「速通」教程，README 里按章节列了竞赛常用的扩展知识点（Stolz 定理、Wallis 公式、区间再现、Euler 常数等）。
- [newbiesilas/cmc-calculus-prep-guide](https://github.com/newbiesilas/cmc-calculus-prep-guide)：基于第 1–17 届共 183 道初赛题统计的考点地图，分 8 个模块讲方法论（不含题目原文）。

## 四、复习路线建议

结合你正在学数分 B1（目前在 §2.1 数列极限）：

| 阶段 | 时长 | 做什么 |
|------|------|------|
| 第一轮：跟课 + 模块扫盲 | 跟着课程进度 | 每学完课本一章，读讲义对应模块，做 `02-真题精讲` 里标注该模块的题。上课学到哪，竞赛就补到哪。 |
| 第二轮：真题套卷 | 2–3 周 | 课程学完后，从第 1 届做到最新一届初赛，**每套严格限时 150 分钟**。做完对照讲义，记下「哪类信号没识别出来」。 |
| 第三轮：专项突破 | 1–2 周 | 只攻错得最多的 2–3 个模块；每天 5 道填空练速度 + 1 道压轴练耐力。 |
| 考前 3 天 | — | 只看讲义里的公式表、信号表和易错点，不做新题。 |

**考场时间分配**（150 分钟）：前 60 分钟做完填空和有把握的解答题；60–110 分钟做中等难度的解答题；110–140 分钟做压轴题的前几问；最后 10 分钟检查填空（换元换限、符号、收敛域）。解答题即使算不完也要写出关键步骤，有步骤分。

> 注意：初赛通常在 11 月中旬左右举行，具体日期以本校通知为准。如果今年的初赛已经报名截止或已经结束，就按上面的路线为下一届做准备；一年级下学期学完多元微积分后参加，效果最好。
